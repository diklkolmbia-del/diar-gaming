# راه‌اندازی سایت دیار گیم

این نسخه یک وب‌سایت فارسی و راست‌چین برای انتشار اخبار، آموزش و معرفی بازی‌هاست. با Flask و SQLite ساخته شده و برای شروع روی کامپیوتر یا محیط پایتون قابل اجراست.

## ۱) نصب
Python نسخه 3.10 یا جدیدتر را نصب کن. سپس در پوشه پروژه اجرا کن:

```bash
python -m venv .venv
```

فعال‌سازی محیط:
- ویندوز: `.venv\Scripts\activate`
- لینوکس / مک: `source .venv/bin/activate`

بعد:
```bash
pip install -r requirements.txt
python app.py
```

سایت در نشانی `http://127.0.0.1:5000` باز می‌شود.

## ۲) ورود مدیر
برای اولین اجرای محلی:
- نام کاربری: `admin`
- رمز عبور: `ChangeMe123!`

**حتماً قبل از انتشار عمومی، رمز را عوض کن.** در محیط اجرا متغیرهای `ADMIN_USERNAME` و `ADMIN_PASSWORD` را تنظیم کن. همچنین `SECRET_KEY` را به یک مقدار تصادفی و محرمانه تغییر بده. برای مثال در لینوکس/مک:

```bash
export ADMIN_USERNAME="نام‌کاربری‌دلخواه"
export ADMIN_PASSWORD="یک-رمز-قوی-و-منحصربه‌فرد"
export SECRET_KEY="یک-کلید-تصادفی-طولانی"
python app.py
```

اگر پایگاه داده قبلاً ساخته شده باشد، تغییر متغیرهای مدیر، حساب موجود را تغییر نمی‌دهد؛ برای شروع تازه و فقط در محیط آزمایشی، فایل `diar_gaming.db` را حذف کن تا دوباره ساخته شود.

## ۳) تبلیغات و درآمد
در این نسخه فقط جایگاه نمایشی تبلیغات وجود دارد؛ هنوز هیچ درآمدی ایجاد نمی‌شود. برای درآمد واقعی باید:
1. سایت را روی هاست و دامنه منتشر کنی.
2. قوانین و شرایط سرویس تبلیغاتی موردنظر را بررسی کنی.
3. برای پذیرش سرویس، محتوای اصیل و بازدیدکننده واقعی داشته باشی.
4. فقط کد تبلیغاتی رسمی سرویس تأییدشده را در قالب قرار بدهی.

هرگز روی تبلیغات خودت کلیک نکن و از دیگران هم نخواه کلیک مصنوعی انجام دهند. درآمد، تضمینی نیست و به پذیرش سرویس و ترافیک معتبر بستگی دارد.

## ۴) نکات قبل از انتشار عمومی
این پروژه نسخه شروع و آموزشی است. برای استفاده عمومی باید HTTPS، تنظیمات امن کوکی و SECRET_KEY، محافظت CSRF برای فرم‌ها، پشتیبان‌گیری دیتابیس، محدودسازی تلاش ورود و یک روش امن برای مدیریت رمز عبور اضافه شود. حالت `debug=True` را در سرور عمومی فعال نکن.
